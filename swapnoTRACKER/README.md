# Shwapno Price Monitor Dashboard

A real-time price monitoring and market analysis dashboard for Shwapno online catalog products.

## Features
- **Price Tracking & History**: Visual representation of catalog product prices and historic trends.
- **Analytics & Scorecards**: Highlighting top movers, discount opportunities, and category coverage.
- **AMOLED Dark Mode**: Clean modern UI design.

## Live Demo (GitHub Pages)
This project is configured for **GitHub Pages**. Simply enable GitHub Pages in your repository settings:
1. Go to **Settings** > **Pages**.
2. Select **GitHub Actions** (or `main` branch root `/`) as the source.
3. Access the dashboard directly via your GitHub Pages URL!

## Local Development
To launch the dashboard locally:
```bash
python -m http.server 8765 -d frontend
```
Then open `http://localhost:8765` in your browser.
