# Project Instructions - GroceryGOD

## Source Control Mandates
- **Exclusion Policy:** NEVER stage, commit, or push `.ipynb` files (Jupyter Notebooks) to this repository. This includes `gitgod.ipynb` and any other notebooks.
- **Gitignore:** Ensure `*.ipynb` remains in `.gitignore`. If any notebook is accidentally tracked, untrack it using `git rm --cached <file>`.
