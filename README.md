# GroceryGOD // Unified Market Intelligence Engine

GroceryGOD is a high-performance price tracking and comparison matrix for major Bangladeshi grocery stores. It aggregates data from Shwapno, Chaldal, Meena Bazar, Othoba, Metro Mart, Unimart, and ShotejBazar into a unified dashboard for market analysis.

## 🚀 Architecture: Data Chunking & Lazy Loading

To bypass GitHub Pages' 100MB file size limit and optimize browser performance, GroceryGOD employs a **Synchronous Manifest-Based Lazy Loading** strategy.

### 1. Dynamic Pinning (Shwapno)
- **Automatic Discovery:** The `swapnoTRACKER/dynamic_pins.py` script uses XPath to find active promotional links (e.g., Summer Fest, Hot Deals) directly from the Shwapno homepage.
- **Auto-Priority:** Discovered links are automatically injected into the `pinned_deals` group in the configuration and highlighted with a `📌` icon in the UI.

### 2. Deep Scraping & Unit Normalization
- **Multi-Tab Capture:** The Shwapno scraper identifies complex deal pages (like `buy-save-more-2`) and iterates through all sub-category tabs.
- **Deep Extraction (ShotejBazar):** The new ShotejBazar tracker performs deep dives into individual product pages to extract precise pack information (e.g., "40gm x 20pcs") for 100% accurate unit price normalization.

### 3. Frontend Lazy Loading
- **Shwapno-First:** On initial load, ONLY **Shwapno** data is fetched.
- **On-Demand Fetching:** Other stores are fetched asynchronously ONLY when the user enables them via the sidebar.
